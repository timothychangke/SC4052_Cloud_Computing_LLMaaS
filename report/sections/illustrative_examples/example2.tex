The second example demonstrates the pipeline's ethical safeguard: when the
context-extraction module identifies a conversation as emotionally sensitive,
the system suppresses ad delivery entirely and returns a purely supportive
response.  This gate operates independently of the ad inventory --- even if
highly relevant ads existed, they would not be shown.

\subsubsection{Stage 1: Context Extraction and Sensitivity Detection}
\label{subsubsec:example2-context}

The user opens a conversation about personal stress and mental wellbeing.
The context extractor returns:

\begin{lstlisting}[style=jsonstyle, caption={Context extraction output for a
sensitive mental-health query.}, label={lst:example2-context}]
{
  "intent":          "general_question",
  "ad_receptivity":  "low",
  "purchase_signal": 0.00,
  "topics":          ["mental health", "stress", "anxiety"],
  "entities":        []
}
\end{lstlisting}

\noindent
Two signals jointly trigger suppression.  First, \texttt{purchase\_signal}
is~0.00, indicating no commercial intent whatsoever.  Second, the topics
array contains members of the hard-coded sensitivity list (\texttt{mental
health}, \texttt{anxiety}, \texttt{grief}, \texttt{financial distress},
and related terms).  The orchestrator evaluates both conditions before
dispatching a retrieval request: if either \texttt{ad\_receptivity} is
\texttt{low} \emph{and} the topic set intersects the sensitivity list, the
ad-matching stage is skipped.

\subsubsection{Stage 2: Ad Matching Skipped and Response Generation}
\label{subsubsec:example2-skip}

Because the sensitivity gate fires, the orchestrator bypasses the retrieval
pipeline entirely. No embedding call, vector search, or scoring is
performed, and no \texttt{<sponsored\_context>} block is assembled.  This is
stricter than the threshold-rejection path in
Example~\ref{subsec:example-irrelevant}, where the pipeline searched but found
no qualifying ads; here, it does not search at all.  The LLM receives only the
conversational instruction set, responds with empathetic guidance free of
product mentions, and no impression event or campaign spend is recorded.
